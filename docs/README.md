# 项目文档说明

本目录存放与真实代码同步的工程说明和联调证据。

当前开发依据为用户提供的 V1.1 完整文档包与毕业设计任务书。第 2 阶段已将数据库设计落地到项目 `sql/` 目录；第 4 阶段已实现组织与设备生命周期；第 5 阶段已实现故障报修与人工维修工单核心闭环。正式设计、API 与测试记录直接同步在文档包的 `02_开发设计文档.md`、`04_系统设计文档.md`、`06_API接口文档.md`、`07_测试报告.md`，避免产生第二份规范。

`evidence/` 中的第 4 阶段截图来自 2026-09-11 的真实前后端联调：

- `stage4-organization.png`：组织三级关系；
- `stage4-equipment-list.png`：设备台账、状态与操作；
- `stage4-equipment-detail.png`：详情聚合、二维码与状态履历。

第 5 阶段截图来自 2026-09-12 的真实 Vue、Spring Boot、MySQL、Redis 联调：

- `stage5-reporter-created.png`：报修提交后自动生成待派单工单；

第 6 阶段已完成 UI 统一与双分辨率浏览器验证，详细修改内容、实测表格和论文截图建议见 [UI优化结果](UI优化结果.md)。对应截图保存在 `evidence/stage6-*.png`。

第 7 阶段已完成仓库、备件、库存流水与工单领用/退库闭环，详细设计、API、测试结果和风险见 [第7阶段实现与测试报告](第7阶段实现与测试报告.md)。真实浏览器证据保存在 `evidence/stage7/`。

第 9 阶段已完成可解释 Top3 智能派单、主管人工确认、SLA 规则/超时升级与站内消息，详见 [第9阶段实现与测试报告](第9阶段实现与测试报告.md) 和 [智能派单算法实验](智能派单算法实验.md)。真实 Chrome 证据保存在 `evidence/stage9/`。
