报修提交后保持 SUBMITTED，设备仍为 RUNNING；管理员或授权主管确认后才创建 PENDING_ASSIGN 工单并将设备置为 FAULT。工单状态以代码枚举为准：PENDING_ASSIGN、ASSIGNED、PROCESSING、SUSPENDED、PENDING_ACCEPT、COMPLETED、UNREPAIRABLE、CANCELLED。

工程师领退备件须具有相应操作权限，为当前指派人员，工单处于 PROCESSING，并具有对应仓库授权；领用仅限 REPAIR 工单。每条工单领用记录对应一条 ISSUE 流水，一条库存流水对应 0..1 条工单领用记录。`sql/05_schema_inventory.sql` 对领用记录的 `transaction_id` 设置了 NOT NULL 和唯一约束 `uk_work_order_spare_transaction`；两表为逻辑关联，没有物理外键。普通入库、调拨、盘点等流水无需领用记录。

MySQL 备份、恢复及每日任务注册脚本已提供；2026-10-01 验证记录明确未注册 Windows 备份任务，不能据脚本存在声称已启用定时备份。

最新验证记录中的后端 319 个方法是全量回归与新增方法定向回归后的 Surefire XML 合集，不是同一次运行的 319 项全量测试。清理文档未重新执行业务测试。

`evidence/` 保留历史联调截图；算法实验保留原实验条件和结果。这些材料不代表当前版本重新验证的结果，截图用于论文前应逐项核对当前界面与业务规则。
