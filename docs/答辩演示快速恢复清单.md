# 答辩演示快速恢复清单

1. 检查 MySQL 3306：`Get-Service MySQL80`；数据库名 `industrial_maintenance`。
2. 检查 Redis 6379：`redis-cli ping` 应返回 `PONG`。
3. 后端：设置 `SPRING_PROFILES_ACTIVE=local` 与不少于 32 字节的 `JWT_SECRET`，在 `backend` 执行 `java -jar target/industrial-maintenance-backend-0.0.1-SNAPSHOT.jar`。
4. 健康检查：访问 `http://127.0.0.1:8080/actuator/health`，应为 `UP`。
5. 前端：在 `frontend` 执行 `npm run dev -- --host 127.0.0.1`，访问 `http://127.0.0.1:5173`。
6. 若登录状态异常：清理浏览器站点数据后重新打开，不修改数据库或绕过权限。
7. 开发演示五角色：`admin`、`supervisor`、`engineer`、`warehouse`、`reporter`；统一演示密码仅见本地部署说明，不用于生产。
8. 端口冲突：`Get-NetTCPConnection -State Listen | ? LocalPort -in 5173,8080,3306,6379`，只终止确认属于本项目的 5173/8080 进程。
9. 数据异常时不要现场删除开发库；使用已验证备份恢复到新的演示库并切换 `DB_URL`。
10. 演示顺序控制在 8—10 分钟，优先主维修闭环、库存事务、智能派单、知识推荐和 KPI。
